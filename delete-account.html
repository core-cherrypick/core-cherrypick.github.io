Lintori 계정 삭제 안내

Lintori 앱의 계정과 저장한 데이터를 삭제하는 방법입니다. 앱에서 바로 삭제할 수 있고, 앱을 쓸 수 없는 경우에는 이메일로 요청할 수 있습니다.

앱 이름 Lintori (링토리)
문의 core.cherrypick@gmail.com

1. 앱에서 삭제하기

  1. Lintori 앱에서 설정 탭을 엽니다.
  2. 내 정보 관리를 누릅니다.
  3. 화면 아래의 계정 삭제를 누릅니다.
  4. 삭제되는 항목을 확인하고, 입력 칸에 삭제를 입력한 뒤 계정 삭제를 누릅니다.
  5. Apple로 로그인한 계정은 Apple 인증 창이 한 번 더 뜹니다. 인증하면 삭제가 완료됩니다.

삭제가 끝나면 로그인 화면으로 돌아갑니다. 삭제는 즉시 이루어지며 되돌릴 수 없습니다.

2. 앱을 쓸 수 없을 때 이메일로 요청하기

앱을 이미 지웠거나 로그인할 수 없는 경우, 아래 내용을 적어 core.cherrypick@gmail.com으로 보내 주세요.

  • 제목: Lintori 계정 삭제 요청
  • Lintori에 로그인할 때 쓴 이메일 주소
  • 로그인 방식: Apple · Google · 카카오 중 하나

본인 확인을 위해 로그인에 쓴 이메일 주소로 회신을 보내 확인을 받은 뒤 삭제합니다. Apple의 「나의 이메일 주소 가리기」를 쓰셨다면 iPhone 설정의 Apple 계정 → 로그인 및 보안 → 「Apple로 로그인」에서 Lintori에 쓰인 중계 주소를 확인해 함께 적어 주세요. 확인이 끝나면 지체 없이 삭제하고, 완료되면 메일로 알려 드립니다.

3. 삭제되는 정보

  • 계정 정보 — 이메일 주소, 로그인 제공자 식별자, 로그인 제공자가 보낸 이름(닉네임)·프로필 사진 주소, 약관 동의 기록
  • 저장한 모든 게시물 — 링크·메모·제목·태그·카테고리, 자동 분류 결과와 요약문
  • 저장한 파일 — 게시물 이미지, 페이지에 넣은 사진·영상·파일
  • 카테고리·폴더·템플릿 등 직접 만든 분류
  • 공개한 게시물 — 다른 사용자의 탐색 화면에서도 사라집니다
  • 신고·차단·숨김 기록, 문의 내역과 첨부 사진

Apple 또는 카카오로 로그인한 계정은 삭제할 때 Lintori와의 로그인 연결도 끊습니다 (Apple 로그인 토큰 철회, 카카오 연결 끊기).

4. 삭제 후에도 남을 수 있는 정보

  • 다른 사용자가 이미 저장해 간 공개 링크 — 공개한 링크를 다른 사용자가 자기 보관함에 저장했다면, 그 링크는 그 사용자의 게시물로 남습니다(이용약관 제7조의2). 저장해 간 사람의 계정과 연결되며, 삭제한 계정과는 연결되지 않습니다.
  • 외부 사업자가 보관하는 사본 — 자동 분류에 보낸 게시물 정보는 Anthropic이 받은 날부터 30일 이내에 자동으로 삭제합니다. 광고 사업자(Google, AppLovin)가 광고를 보여 줄 때 처리한 기기 정보·IP 주소는 각 사업자의 정책에 따라 보관됩니다.
  • 보안 기록 — 인증 서버의 로그인 기록은 서비스 운영 사업자의 보관 주기가 지나면 자동으로 삭제됩니다.

현재 Lintori는 유료 결제가 없어, 법령에 따라 따로 보관해야 하는 거래 기록이 없습니다.

5. 계정은 두고 일부만 삭제하기

계정을 유지한 채 게시물만 지우려면 앱의 보관함에서 게시물을 길게 눌러 여러 개를 고른 뒤 삭제하거나, 게시물을 연 화면의 ⋮ 메뉴에서 하나씩 삭제할 수 있습니다. 공개한 링크는 게시물을 연 화면의 ⋮ 메뉴 → 공개 설정에서 비공개로 바꿀 수 있습니다.

자세한 내용은 개인정보 처리방침과 이용약관에 있습니다.
